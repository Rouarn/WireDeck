WireDeck 安装说明
=================

1. 安装
   把 WireDeck 拖进「应用程序」文件夹。

2. 首次打开
   在「应用程序」里右键 WireDeck → 选择「打开」→ 再点一次「打开」。
   应用没有经过 Apple 公证，直接双击会被系统拦截，这是正常现象。

   如果仍提示"已损坏"或"无法打开"：
   - 打开「系统设置 → 隐私与安全性」，在页面底部点「仍要打开」；
   - 或打开「终端」，执行：
     xattr -dr com.apple.quarantine /Applications/WireDeck.app

3. 手机准备
   - 设置 → 关于手机 → 连续点击「版本号」开启开发者选项；
   - 设置 → 开发者选项 → 无线调试，打开开关；
   - 手机与电脑连接同一个 Wi-Fi。

4. 连接手机
   方式一（推荐，扫码）：
     应用 → 设备 → 添加设备 → 扫码配对，
     手机：无线调试 → 使用二维码配对设备，扫描电脑上的二维码。

   方式二（配对码）：
     手机：无线调试 → 使用配对码配对设备，
     把显示的 IP、配对端口、6 位配对码填进应用后点「配对」，
     再用无线调试主页显示的端口点「连接」。

5. 投屏（可选）
   设备页点「投屏」即可在电脑上操作手机。
   小米 / 红米设备需要在「开发者选项 → USB 调试（安全设置）」中
   打开开关，否则投屏画面正常但无法用鼠标键盘操作。

6. 关于 adb / aapt2 / scrcpy
   应用已内置 adb、aapt2 与 scrcpy，无需安装 Android SDK。

Windows（实验性）
1. 下载 WireDeck-windows-amd64.zip 后完整解压（不要只解压 exe）；
2. 运行 WireDeck.exe；
3. 若 SmartScreen 提示，点「更多信息 → 仍要运行」。

系统要求
- macOS 11 及以上 / Apple Silicon（正式支持）
- Windows 10 / 11 x64（实验性）
- Android 11 及以上
