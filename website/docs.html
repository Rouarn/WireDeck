使用文档

从安装到连接，再到常用功能，几分钟上手。

安装

  1. 从 GitHub Releases 下载 DMG。
  2. 双击打开，把 WireDeck 拖进「应用程序」。
  3. 首次打开时右键 → 打开（应用未公证，直接双击会被系统拦截）。

如果提示「已损坏」或「无法打开」，在终端执行：

xattr -dr com.apple.quarantine /Applications/WireDeck.app

然后到「系统设置 → 隐私与安全性」点「仍要打开」。

手机准备

  1. 设置 → 关于手机 → 连续点击「版本号」，开启开发者选项。
  2. 设置 → 开发者选项 → 打开「无线调试」。
  3. 手机与电脑连接同一个 Wi-Fi。

连接手机

方式一：扫码配对（推荐）

  1. 应用：设备 → 添加设备 → 扫码配对，窗口显示二维码。
  2. 手机：无线调试 → 使用二维码配对设备，扫描电脑上的二维码。
  3. 配对成功后自动连接，设备出现在列表中。

方式二：配对码

  1. 手机：无线调试 → 使用配对码配对设备，记下 IP、配对端口与 6 位配对码。
  2. 应用：填入信息，点「配对」。
  3. 再用无线调试主页显示的端口，点「连接」。

常见问题

看不到 USB 连接的手机

确认手机已开启「USB 调试」，并在手机上点「允许」授权弹窗。应用使用标准 adb 端口，与系统共享设备。

扫码后一直等待

确认手机与电脑在同一局域网；扫码后不要刷新二维码，等待 10 秒左右。

提示无法打开应用

按上面的 Gatekeeper 步骤放行，或执行 xattr 命令。

系统要求

  • macOS 11 及以上
  • Apple Silicon（当前版本）
  • Android 11 及以上
