更新日志

v0.2.2 · 2026-10-30（Alpha / 测试版）

Windows 兼容性修复。

  • 修复 Windows 上反复弹出 CMD 黑框
  • 修复 Windows 文件推送/拉取不可用
  • 内置 aapt2，修复 APK 解析与中文应用名
  • 修复导出文件名中文/括号截断问题
  • 修复投屏无法唤起，并增加诊断日志
  • 更新应用图标；优化安装队列长文件名显示

v0.2.1 · 2026-10-30（Alpha / 测试版）

双语界面与 Windows 实验性构建。

  • 界面支持中文 / English 切换，覆盖全部页面
  • Windows 实验性构建（含内置 adb 与 scrcpy）
  • 修复多语言词条缺失、1970 安装时间、英文标签换行
  • 投屏按钮增加「USB 调试（安全设置）」悬停说明

v0.2.0 · 2026-10-31（Alpha / 测试版）

功能增强与体验优化。

  • 新增 scrcpy 投屏，可在电脑上直接操作手机
  • 新增 USB 转无线、批量加载应用名、日志导出
  • 新增版本更新检查（基于 GitHub Releases）
  • 文件页重构：双栏布局、拖放添加、批量推送与拉取、清空列表
  • 设备卡片显示 IP、Wi-Fi 信号与最后在线时间
  • 记住窗口大小与位置；点击关闭直接退出
  • 修复 Wi-Fi 信号解析、转为无线连接重试、更新检查 404
  • adb 与 scrcpy 复用同一份 adb，安装包减小约 18MB

v0.1.0 · 2026-10-30（Alpha / 测试版）

首个公开测试版本。

  • 设备：扫码配对、配对码配对、启动时自动重连历史设备
  • 应用：列表与详情、卸载、启动、强制停止、清除数据、导出 APK
  • 安装：拖放安装、真实进度、取消、失败原因建议
  • 文件：截图、推送、拉取、设备目录浏览
  • 日志：实时 logcat、按应用过滤、崩溃 / ANR 摘要与复制
  • Shell：独立控制台、快捷命令、输出复制
  • 内置 adb，无需安装 Android SDK
